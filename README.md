メルカリの「今売れている商品」のリアルタイムデータは私からは見られないため、以下は有望なジャンルと、自分で裏取りする方法です。

狙いやすいジャンル
トレカ・ホビー・アートトイ(新品)
メルカリには売れ筋ランキングがありませんが、2025年の検索ワード1位は「ラブブ」で、トップ10の半数がポケモン・鬼滅の刃・ちいかわ・ONE PIECEなどのキャラクター・漫画関連でした。単価が高く回転も速いので、予算30万円を回しやすい分野です。ただし再販や増産で相場が急落するリスクがあります。

季節家電(空気清浄機・加湿器・ヒーター等)
花粉症対策家電は平均取引価格が3万円超になることも珍しくなく、シーズン直前に高騰しやすいとされています。今は10月末なので、冬物家電や年末年始需要を狙うのに良い時期です。ただし大型は送料が利益を圧迫します。 
mobinc
ブランドスニーカー・アウトドア系アパレル
ナイキ、アディダス、ザ・ノース・フェイスなどが定番です。セール時の公式通販やポイント高還元を使うと仕入れ値を下げられます。
ゲーム・おもちゃの限定版・プレミア品
予約や再販のタイミングを押さえる戦略が必要です。
本・漫画セット
ある副業の実績では、月30点販売で売上約14万円、利益約5.3万円、利益率36.7%でした。利益率は高めですが、規模が小さく手間がかかるため、30万円の運用には向きません。

「分析して探す」手順
売れた実績を見る: メルカリで検索し、「売り切れ」で絞り込みます。直近30日の売れた個数と価格帯を確認してください。ただし1年以上前に売れた商品は、すでに需要がない可能性があるので日付も見ます。 
aucfan
競合を見る: 同じ商品の「販売中」の出品数と最安値を確認します。
仕入れ値の底を見る: Amazonや楽天の価格推移(Keepaなど)で、今が安値かを確認します。
利益計算: 売値×0.9(手数料10%)−送料−仕入れ値で計算します。目安は利益率15%以上、1個あたり1,000円以上です。
予算30万円の使い方
1商品に全額を入れず、1ジャンルあたり全体の3〜4割までに抑えます。
売れ行きが読めるものを小ロットで試してから、数量を増やします。
在庫が滞留すると資金が動かなくなるため、売れるまでの日数が短いものを優先します。
